# This is the readme for the SORMI families repository - data on spat only. 

This repository contains **raw data** files and code used for analysis. Two kinds of data were generated/created on the spat: glycogen data and resazurin metabolic data, all generated at USDA/ARS @ the Hatfield marine science center.  The glycogen data were generated from the Promega Glycogen Glo assay, following manufacturers instructions. The resazurin data were generated following the standard protocol from Huffmyer et al 2026 (Peer J), read on a Biotek Synergy XL plate reader with resazurin disodium salt purchased from Sigma. 

**Data Files contained in this repository:** \
raw plate files with fluorescence data (resazurin) \
raw plate files with luminescence data (glycogen) \
meta data and size data for the fluorescence data \
summarized glycogen data (individual measurements) and mean/SE per family \
summarized glycogen/resazurin data used in statistical analysis (csv dataset)\
\
**Code files:** \
Resazurin processing code \
Statistical analysis of effect of resazurin/glycogen content on survival during lab challenges...
